# MIPS CPU 원본 시뮬레이션 검증 근거

[README](../README.md) · [재현 계획](verification-plan.md)

> **근거:** 개인 발표자료 「MIPS CPU 설계 및 동작 검증」(2026-06-09, 19쪽), 통합 시뮬레이션 파형·Tcl Console 화면 및 사용자 제공 설명. 아래 기록은 **당시 검증 결과**이며 이번 문서 작업에서 RTL을 재시뮬레이션한 결과가 아닙니다.

## 통합 실행의 관측값

| 신호·카운터 | 원본 결과 | 해석 |
| --- | ---: | --- |
| Halt | syscall 종료 조건에서 활성화 | v0=10인 syscall에서 종료 신호 출력 |
| Total_Cycles | **1,646** | 최종 통합 시뮬레이션 사이클 카운트 |
| R | **575** | R형 분류 카운트 |
| I | **1,032** | I형 분류 카운트 |
| J | **39** | J형 분류 카운트 |
| 합계 | **575 + 1,032 + 39 = 1,646** | 유형별 합계와 전체 카운트 일치 |

최종 파형·콘솔 화면과 발표자료 p.18의 종료 조건 설명에 근거합니다. 카운트 합계가 같다는 사실이 모든 명령의 의미론적 정확성, 전체 MIPS ISA 호환성, 타이밍 충족을 단독 증명하지는 않습니다.

**종료 조건의 의미:** Halt 신호가 활성화되어 테스트 환경에서 시뮬레이션이 종료됐음을 확인했습니다. CPU의 내부 클럭을 자동으로 차단하는 하드웨어 게이팅 동작으로 설명하지 않습니다.

## 모듈별 보고서 검증 항목

| 영역 | 발표자료에서 설명한 검증 | 근거 |
| --- | --- | --- |
| Control Unit, ALU, Imme Extend | 명령어 유형별 제어 신호, 부호/무부호 연산 및 즉시값 확장 | pp.4–7 |
| Register File | 0번 레지스터의 쓰기 보호 | pp.8–10 |
| Program Counter | PC+4·분기 및 외부 예외 0x0800 진입 | pp.8–10 |
| Instruction / Data Memory | 워드 단위 주소 접근과 제어 신호 동작 | pp.11–14 |
| Syscall / Statistics | v0=10 종료 조건과 R/I/J 집계 | pp.15–16, 18 |
| CP0 | 외부 예외 감지·EPC·eret 경로 | p.17 |

시험에서 관찰된 동작 범위이며, 전 입력 벡터를 망라한 완전 검증이나 FPGA 물리적 타이밍 검증으로 표현하지 않습니다.

## GitHub 재현성과 다른 점

원본 발표자료의 파형·로그 화면은 확인됐지만, 현재 저장소에는 당시 사용한 테스트벤치·inst_main.mem·inst_exc.mem·원본 Tcl 로그·VCD가 포함돼 있지 않습니다. 따라서 **발표자료로 확인된 과거 시뮬레이션 성공**과 **현행 저장소에서 즉시 재현 가능한 테스트 상태**는 다릅니다.

추후 테스트벤치를 새로 작성할 경우 새 독립 검증으로 명시하고, 과거 원본 파형을 임의로 재생성했다고 표현하지 않습니다. 원본 보고서 전체·학번 포함 화면을 공개하지 않았으며 이번 PR은 텍스트 문서만 변경합니다.
